# Changelog

## 0.1.0

Initial release.

- Inline, product-tour style playback: spotlighted lines, dimmed context, Markdown bubble with Back / Next / Finish.
- Generate walkthroughs with Claude Code from a file, selection, folder, whole workspace, or git diff.
- Manual authoring: add steps from a selection, edit / reorder / delete from the sidebar.
- Edit-resilient steps (anchor re-location), hot reload while playing.
- Import from file or URL; export to Markdown with code excerpts.
